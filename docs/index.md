# docs インデックス（dsh-gitbash-win）

インストール・検証・セキュリティ・更新追従の手順をこのディレクトリに置いています。

## 文書一覧

- [install-windows.md](install-windows.md):
  Windows へのインストール手順。方法 A（`dsh plugin add`）と方法 B（手動配置）、
  プロファイルごとの設定、初期確認を説明します。
- [verification.md](verification.md):
  Windows 実機なしで動作確認する方法。Linux で実行できるテストと Web E2E、
  仮想化環境での Windows 検証手順を説明します。
- [security.md](security.md):
  セキュリティとサンドボックスの意味論。fail-closed の根拠、
  ACL restricted-token の非互換性、監査項目を説明します。
- [updating-dsh.md](updating-dsh.md):
  DSH 本体の更新に追従する手順。版固定箇所のチェックリストと、
  テスト／E2E の再実行手順を説明します。
